This directory contains Protocol Buffer (.proto) schema definitions that are
licensed under the MIT License, separate from the GPL v3 license of the
GemellStudio project.

Purpose:
--------
These .proto files define the data interchange format for geometry nodes
between Blender (GemellStudio, GPL v3) and external proprietary services.

Legal Basis:
------------
- GPL projects may contain files with different licenses (precedent: Linux kernel)
- .proto files are interface definitions, not implementation code
- Generated code from 'protoc' inherits the license of the .proto file (MIT)
- Both GPL (Blender) and proprietary (external services) code can compile
  and use the same schema without license contamination

Usage:
------
- GemellStudio (GPL v3): Compiles these .proto files, uses generated C++ code
- External Services (Proprietary): Can compile the same .proto files without
  GPL obligations

For more information, see README.md in this directory.
